# SakuraPool P1 Report

## Scope

P1 implements the `src/sakurapool` package, Arrow schema conversion, structured query validation, schema/model registries, deterministic in-memory evaluation, focused tests, examples, and a functional CLI. TAR scanning, runtime/download behavior, deduplication, and real data are excluded.

## Assumptions

- Input datasets are small enough to materialize as Python row mappings.
- `DEFAULT_SCHEMA` is the initial reference contract: non-null string `id`, non-null float64 `value`, nullable string `label`.
- Filtering preserves input order. `limit` is applied after filtering. Null comparisons other than equality/inequality do not match.
- Model registry records input/output schemas only; it does not execute models.

## Dependency pins

Runtime: `pyarrow==18.1.0`. Development: `pytest==8.3.4`, `ruff==0.9.2`, `build==1.2.2.post1`. The build backend is `setuptools==75.6.0`.

## Validation log

The raw command output is stored in `reports/P1/validation.log`; commands, exit codes, environment, and SHA256 values are stored in `reports/P1/metadata.txt`. Generated wheels and caches are intentionally outside the repository.
